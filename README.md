# moneytime-static

ריפו הפצה בלבד. מתפרסם על ידי ה-CI של `tzur669-lab/moneytime-app`:

- `callback.html` — דף ה-redirect של Google OAuth (כתובת ציבורית יציבה,
  רשומה ב-OAuth client ב-Google Cloud).
- `moneytime-pro.apk` — ה-build החתום של אנדרואיד; היעד של מנגנון
  העדכון בתוך האפליקציה.

האפליקציה עצמה מתארחת ב-Cloudflare Pages — https://moneytime.pages.dev/
אין כאן קוד אפליקציה, תיעוד או סודות.
